# WebNovelStudio

Windows x64에서 TXT·EPUB·PDF를 읽고 텍스트를 정리하는 무료 프로그램입니다.

- [홈페이지](https://webnovelstudio.github.io/)
- [WebNovelStudio 0.8.1.zip 다운로드](https://github.com/WebNovelStudio/webnovelstudio.github.io/releases/download/v0.8.1/WebNovelStudio.0.8.1.zip)
- [공개 릴리즈와 패치](https://github.com/WebNovelStudio/webnovelstudio.github.io/releases)
- [방명록 관리 한국어 안내](https://webnovelstudio.github.io/manage/)

배포 ZIP 전체를 압축 해제한 뒤 `WebNovelStudio` 폴더의 `WebNovelStudio.exe`를 직접 실행하세요. Python을 따로 설치할 필요가 없습니다. GitHub의 실제 다운로드 파일명은 `WebNovelStudio.0.8.1.zip`입니다.

기본 배포판은 새 홈페이지와 업데이트 주소를 반영한 0.8.1입니다. 이후 공개 패치는 프로그램의 **도움말 → 업데이트 확인**으로 적용합니다. 홈페이지 다운로드는 이 전체 배포판을 연결합니다.

이 저장소에는 프로그램 실행용 배포 자산과 공개 홈페이지만 게시합니다. 프로그램 개발 소스·사용자 책·개인 설정·방명록 서버 비밀 정보는 포함하지 않습니다.
