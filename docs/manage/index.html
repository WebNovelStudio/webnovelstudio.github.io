방명록 표 열기 ↗

Supabase의 로그인 화면이 나오면 본인 계정으로 로그인하세요.
WebNovelStudio 조직의 프로젝트 접근 권한이 있는 계정만 관리할 수 있습니다.

01 · 읽기

닉네임과 내용을 확인해요.

열리는 표의 이름은 방명록입니다. 닉네임, 내용, 작성일을 보면 누가 언제 어떤 글을 남겼는지 알 수 있어요.

02 · 숨기기와 복원

휴지통 값만 바꾸면 돼요.

표 오른쪽의 휴지통을 TRUE(체크)로 바꾸면 홈페이지에서 숨겨집니다. 다시 FALSE(체크 해제)로 바꾸면 복원됩니다.

숨겨진 글은 자동으로 지워지지 않습니다. 잘못 숨긴 글은 다시 복원할 수 있어요.

03 · 완전히 삭제

필요할 때만 완전히 지워요.

글 왼쪽의 행 선택 칸을 누른 뒤 표 위의 삭제 메뉴(Delete rows)를 선택합니다. 확인 창에서 선택한 글이 맞는지 살펴보고 삭제하세요.

원글을 완전히 삭제하면 연결된 댓글도 함께 삭제됩니다. 먼저 휴지통으로 숨길 수 있어요.

댓글은 별도 표에서 관리해요.

프로젝트의 Table Editor에서 방명록 댓글을 열고, 같은 방식으로 휴지통을 바꾸세요. 글번호는 댓글이 연결된 원글을 가리킵니다. 원글을 숨기면 그 아래 댓글도 홈페이지에서 함께 숨겨집니다.

이것만 기억해 주세요.

  • 글번호·수정번호·작성일·수정일은 그대로 두세요.
  • 글 비밀번호 원문은 저장하지 않습니다. 비밀번호 검증값은 별도 보호 표에 보관합니다.
  • 일반 방문객은 관리 표를 직접 읽거나 수정할 수 없습니다.
  • 공용 PC에서는 관리가 끝난 뒤 Supabase에서 로그아웃하세요.

표가 열리지 않으면 프로젝트 홈에서 로그인 계정과 WebNovelStudio 조직을 확인하세요.
