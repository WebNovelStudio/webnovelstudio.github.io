TXT·EPUB·PDF 읽기

파일 형식에 따라 사용할 수 있는 독서 기능을 확인하세요.

텍스트(TXT) 뷰어

웹소설이나 메모를 담은 .txt 파일을 열어 글자 크기와 줄 간격을 조절할 수 있습니다. 본문에서 단어를 찾고, 한 페이지 또는 두 페이지 보기로 읽으세요.

이펍(EPUB) 뷰어

.epub 전자책의 본문과 삽화를 함께 보고, 책의 목차에서 원하는 회차로 이동할 수 있습니다. 로컬 TTS로 본문을 이어 들을 수 있습니다.

PDF 뷰어

문서의 그림과 지면 배치를 원본 페이지 그대로 보고 확대하거나 두 페이지를 나란히 펼칠 수 있습니다. PDF 본문은 페이지 이미지로 표시됩니다.

자주 묻는 질문

어떤 파일을 읽을 수 있나요?

TXT·EPUB를 읽을 수 있고 PDF는 원본 페이지 이미지로 보여줍니다. PDF의 OCR·텍스트 검색·복사·TTS는 지원 범위에 포함되지 않습니다.

읽으면서 정리하면 원본도 바뀌나요?

독서 화면의 표시 변경과 파일 도구의 저장은 구분됩니다. 파일 도구에서는 미리보기·검토를 거쳐 결과를 저장하세요.

인터넷이 꼭 필요한가요?

독서와 동봉 음성 자산은 로컬에서 사용합니다. GitHub 업데이트와 광고 번역 등 외부 통신 기능에는 인터넷 연결이 필요합니다.

다른 운영체제에서도 사용할 수 있나요?

현재 배포 대상은 Windows x64입니다. 업데이트에는 설치 폴더를 쓸 수 있는 권한이 필요합니다.

문제를 발견했어요.
